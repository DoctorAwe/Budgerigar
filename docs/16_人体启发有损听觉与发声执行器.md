# 人体启发有损听觉与发声执行器

## 当前小阶段目标

模型不保存或逐点复制外部波形。连续声波先经过耳蜗式频带响应、整流压缩、短时积累与变化量编码，形成每 2.5 ms 一个 16 维的有损感觉状态；共享运动系统只根据该感觉状态重新组织发声。输出允许绝对相位和采样噪声不同，但必须保持内容、时长、能量、基频走势、清浊与主要频谱包络。

## 单一感觉与共享运动状态

32 个近似耳蜗频带产生当前活动与活动变化，投影后由递归听觉上下文压缩为单一感觉流。16 维感觉流是唯一进入发声系统的信息路径，不设置原波形直通、不可变 token 带、双记忆或互相隔离的声源/构音编码。

感觉流进入同一个运动 GRU。呼吸压力、喉部基频、清浊、非周期程度以及 81 点声道频谱包络均从共享运动状态读取。这些读取结果共同决定同一合成帧，因此人体部件具有可诊断的职责，但不能各自保存独立内容或绕开共享运动计划。

## 自身执行器

喉部参数生成相位连续的周期激励与确定性非周期激励；声道包络在频域对激励进行时变整形。每 2.5 ms 产生一个 10 ms 合成帧，通过有状态重叠相加连续输出。执行器保存听觉滤波历史、递归状态、振荡相位和未输出的合成帧尾部，任意输入分块必须与整段运行保持 `1e-4` 内等价。

首版仅使用前三个谐波，导致声道滤波器缺少可用于形成真人音色的高频材料。修正版使用最多 32 个谐波，幅度按近似声门谱倾斜衰减，并屏蔽超过 Nyquist 的分量；无声激励使用相邻确定性噪声之差形成高通噪声。声道包络的直流增益固定为零，低频采用平滑抑制，整体 RMS 增益归一化，呼吸压力独立负责总响度，从结构上减少低频轰鸣捷径。

## 训练与验收

主要损失是多尺度幅度/对数幅度频谱、能量包络、F0/清浊代理及冻结真实音频评估器的内容损失。波形 L1 仅保留很低权重以限制严重漂移；不使用 SI-SDR 作为训练目标或通过条件。

验收包括冻结内容准确率、不同数字输出间距、感觉状态打乱与均值替换、发声时长比、能量包络误差和人工试听。通过只表示模型能从有损感觉重新发出相似短音，不表示已经具备听完后的记忆、思考间隔、人格音色或自身反馈；这些能力必须在本阶段通过后逐项接入。

## 声门宽带化后的平衡修正

单纯增加谐波数量并不能自然获得清晰语音。32 谐波实验使预测 F0 升到约 `258.5 Hz`（目标约 `161.9 Hz`），频谱质心和高频能量分别达到目标的 `2.39` 和 `4.14` 倍，可懂度反而降到 `39%`。因此执行器需要的是受约束的声门谱倾斜，而不是无限扩展高频。

平衡版保留统一感觉流和统一运动状态，不增加双记忆通道或外置降噪器。它使用 16 个谐波、较陡的 `1/h^1.7` 谱倾斜、平滑的 3 kHz 高频搁架，并联合监督 F0、浊音、气压和非周期性。训练从宽带化之前的 step 500 检查点重新分支；选择模型时同时检查可懂度、感觉消融、F0 误差、频谱质心和高频能量，避免把“更亮”误判为“更像人声”。

step 800 的试听证明内容路径已开始工作，但 F0 仍漂移至 `312.9 Hz`。原先在归一化空间使用 Smooth-L1，使这类大偏差处在梯度不足的区域。校正版把喉部可达 F0 连续限制为 `70–260 Hz`，按 Hz 尺度监督，并在训练期比较目标与输出的归一化频谱形状、质心和高频占比。限制来自发声器本身及其学习目标，不增加程序化发声状态，也不在输出端添加降噪处理。

声源平衡后，step 1100 的 F0 和频谱比例已合理，但内容准确率仍为 `58%`。因此后续不再改声门，而让冻结听觉网络的中间表征成为构音知觉目标：输出与真实声音不仅要得到相同数字标签，还要在卷积听觉特征中接近。该监督仅在训练期提供感觉相似性，推理结构仍是低维感觉、统一运动状态和人体启发执行器。
