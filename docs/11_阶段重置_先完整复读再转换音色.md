# 阶段重置：先完整复读，再转换音色与语调

> 历史方案说明：本文中的 codec token tape、单调读指针和直接复制路线已经实验否决，不再作为正式模型结构。当前方案见 [连续潜空间神经复读重构](12_连续潜空间神经复读重构.md)。本文仅保留阶段决策与失败过程供复盘。

## 决策

项目主线从“直接把任意输入复读为固定目标声线”调整为：

1. 先完整复制输入语音；
2. 再保持内容不变地转换音色；
3. 最后加入模型自身语调、人格和表达习惯。

此前实验同时要求内容记忆、时序对齐、声学生成和音色转换，平均模板失败无法准确归因。新路线先建立可听、可测、可逐级退化的复制基线。

## 阶段 A：延迟式完整复制

模型接收实时音频流，输入句子结束后保持约 160–280 ms 的连续神经思考延迟，然后复读同一段输入。此阶段输出保留：

- 原说话人的音色；
- 原始语调与节奏；
- 完整语言内容；
- 停顿、重音和时长关系。

此阶段不训练目标声线，不使用跨说话人平行目标。训练目标就是当前输入自身。

### 表示选择

仅复制 log-Mel 不能证明声音可完整恢复，因此正式复制链路使用可重建波形的神经音频 codec token。原始波形作为最终真值；Mel 只保留为诊断特征。

数据流为：

`waveform → causal codec encoder → ordered codec tokens → delayed neural readout → codec decoder → waveform`

codec 与数据缓存下载、真实音频重建、GPU 训练均在 Colab 执行。

### 模型职责

- 有序 token tape 保存需要逐项重放的 codec token，保证内容和细节不被抽象理解层替代。
- 连续写时钟由声学证据驱动，记录输入积累进度。
- 连续 readiness 与延迟积分器学习“听完后稍作停顿”，不设置 LISTEN/END/PLAY 状态。
- 单调读指针只能向前消费 token tape，避免倒序、漏读和重复。
- AutoMachine 理解层可以读取 token tape 并形成整体理解，但阶段 A 不允许它修改待复制 token；先证明复制链路本身可靠。

## 阶段 B：流式与长句稳定性

在阶段 A 通过后，验证：

- 不同句长、静音长度、语速和输入音量；
- Colab 麦克风分块与不规则 chunk；
- 多句连续输入而不清空全部高层理解；
- 局部 token tape 正确分配与回收；
- 高层 token 的记忆范围由 optimizer 决定，不按 `tick × 层数` 截断。

## 阶段 C：只转换音色

冻结或强约束已通过的内容复制路径，仅在 codec decoder/声学渲染端加入目标说话人条件：

`已验证的内容 token + 目标音色 embedding → 目标声线 waveform`

这一阶段保持输入语调、节奏、句长和内容不变，只改变音色。必须同时比较：

- 同音复制基线；
- 目标音色输出；
- 输入消融；
- 音色条件消融。

如果内容指标相对阶段 A 明显下降，则音色转换不得通过。

## 阶段 D：模型自身语调与人格

在音色转换通过后，再加入稳定人格 embedding、语调规划 token 和表达习惯。人格只作用于韵律/渲染层，不能绕开单调内容指针或重写句子内容。

## 阶段 A 验收

### 行为

- 输入发声期间误输出率 `<1%`；
- 思考间隔期间误输出率 `<1%`；
- 输出必须在输入结束后至少 160 ms、至多 320 ms 内开始；
- 输出截断率与全静音率均为 `0`。

### 内容与时序

- codec token 准确率 `>99%`；
- token 漏读、重复、倒序率分别 `<0.5%`；
- 输出长度相对输入误差 `<2%`；
- 正确输入检索 Top-1 显著高于随机且在多个随机种子上稳定。

### 波形

- 必须保存可播放输入、目标和复读输出样本；
- 报告 SI-SDR、STOI、波形/频谱距离与延迟对齐误差；
- 至少 3 个随机种子和逐句 bootstrap 95% 置信区间；
- 最终进行人工听测，检查漏词、重复、倒序、爆音和累计漂移。

## 立即停止的工作

- 暂停目标说话人 `arctic_slt` 的端到端生成训练；
- 暂停用目标声线 Mel L1 判断内容记忆；
- 暂停继续调高层语义探针、音色损失和人格 embedding；
- 保留已有 checkpoint 与失败报告，只作为后续音色转换对照。
