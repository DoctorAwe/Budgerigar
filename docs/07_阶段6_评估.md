# 阶段 6：评估与消融实验

## 测试矩阵

测试集按四个轴分层：见过/未见输入说话人、见过/未见文本、干净/噪声、短句/长会话。普通话与英语分别报告，不把平均值混为单一结论。

## 客观指标

| 目标 | 指标 | 说明 |
|---|---|---|
| 内容 | WER/CER、SSL 内容距离 | 同时测原始输入作为 ASR 参考 |
| 目标音色 | target speaker cosine | 输出应靠近固定目标 |
| 隐私/解耦 | input speaker cosine、识别准确率 | 越低越好，但不能牺牲内容 |
| 韵律 | 时长比、停顿 F1、F0 correlation/分布 | 区分轮廓与绝对音高 |
| 音质 | DNSMOS/UTMOS 类指标 | 只作辅助，不替代人评 |
| 流式 | RTF、首包、P50/P95/P99 延迟 | 报告硬件和 batch=1 |
| 稳定性 | 10/30/120 秒漂移、内存曲线 | 检查长期状态污染 |

### 复读时间轴专项指标

- 听取误发声率：源句仍在输入时，连续发声强度超过阈值的帧比例。
- 思考误发声率：源信号结束至目标复读开始之间的发声比例。
- 复读有声召回：目标复读有声帧中，模型发声强度达到阈值的比例。
- 全静默率：整条 episode 从未产生有效发声的样本比例。
- 启动偏差：预测首次发声与目标真人复读首次有声帧之间的毫秒差。
- 分区 Mel L1：分别报告听取、思考和复读区间，禁止只报告全局平均值。

Smoke 阶段暂定门槛：听取和思考误发声率均 `< 5%`，复读有声召回 `> 50%`，全静默率 `< 10%`。这些是结构诊断门槛，不是最终产品质量指标。

通过时间轴门槛后不得直接宣称复读成功。还必须比较正确平行目标、随机打乱目标、目标说话人平均模板和静默基线；只有模型输出显著更接近当前句子的正确目标，才能证明长期隐状态保存了输入内容。

内容 smoke 暂定门槛：正确目标相对打乱目标的 L1 优势 `> 0.02`，逐句胜率 `> 75%`，16 候选 Top-1 至少达到随机机会的 3 倍，并且移除输入后正确目标 L1 至少恶化 `0.02`。这些阈值用于发现内容捷径，后续仍需 ASR/WER 和人类试听。

若输入消融劣化通过、但正确/打乱目标与检索失败，应判定为“输入影响输出，但句子内容不可区分”，通常意味着记忆瓶颈或目标模板捷径，而不是完全忽略输入。

若预测到目标平均帧模板的距离显著低于到正确目标句子的距离，应直接判为模板坍缩。此时继续增加同类声学训练步数通常只会改善平均音色/能量，不构成内容学习；必须引入独立内容目标和可恢复性探针。

说话人相似度模型可能受语言和情绪偏置，必须用多个目标说话人真实样本校准阈值。

## 主观评测

- MOS：自然度与音质，5 分制。
- SMOS：与目标声线的相似度。
- ABX 内容一致性：哪一个输出更忠实复述输入。
- AB 韵律偏好：在不泄漏输入身份的前提下比较自然度。
- 每个条件至少 20 条样本，顺序随机、音量归一，报告均值和 95% 置信区间。

## 必做消融

1. 无层级记忆 vs 短窗口 vs 完整层级记忆。
2. 无身份对抗 vs 有身份对抗。
3. 无韵律输入、仅节奏、归一化轮廓三档。
4. 不同层数、状态宽度和更新周期。
5. 零 look-ahead vs 40/80 ms look-ahead。
6. 平行数据量与非平行扩展比例。
7. Mel 路线 vs codec token 路线（仅在后者实现后）。

## 发布门槛

- 达成阶段 0 的内容、音色、实时与连续性目标。
- 未见说话人和噪声条件没有灾难性退化。
- 身份泄漏审计通过，并在模型卡披露限制。
- 所有公开样例均标记为 AI 转换音频，目标声线有明确授权。
