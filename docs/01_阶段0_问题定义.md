# 阶段 0：问题定义与验收标准

## 输入输出契约

- 输入：单通道 PCM 流，首版支持 16 kHz 或 24 kHz，内部统一重采样到 24 kHz。
- 输出：24 kHz PCM 流，语言内容与输入一致，音色为唯一 Budgerigar 声线。
- 状态：同一会话跨 tick 保留；新会话显式 reset；长静音触发软衰减。
- 降级：无语音时输出静音；削波、重叠说话或低 SNR 应给出质量标记。

## 行为时序约束

- 必须先听完整句子或完整表达，再开始复读，禁止把产品实现成同步音色转换。
- 不设置“监听、句末、朗读”等离散程序状态，也不由外部 VAD 直接触发朗读。
- 模型在每个 tick 都接收输入并预测输出；听取期间的正确输出是静默分布，内容足够完整后才自然进入复读声学轨迹。
- 从模型认为输入表达完整到复读发声之间，应保留一小段可感知的“思考时间”。MVP 人格先验为约 160–280 ms，语句间略有变化，避免机械的固定倒计时。
- VAD、能量、停顿长度可以作为网络输入和辅助监督，但不能成为 `if silence > N: start()` 形式的控制规则。
- runtime 只负责分块、张量传递和安全限幅，不替模型决定语句含义是否完整。

该约束并不否认会话 reset、丢包保护等工程机制；它禁止的是用外部状态机代替模型的语句完整性判断和复读意愿。

思考时间同样不由 runtime 执行 `sleep()` 或计时器触发。训练输出时间轴包含这段静默，使神经隐状态学习“内容完整 → 短暂内化 → 自然复读”的行为；未来可将其分布作为人格的一部分学习。

## “模仿”的精确定义

保留：音素序列、词序、停顿位置、大致语速、疑问/陈述等句型轮廓。

重建：音色、绝对音高范围、微观 F0 运动、能量习惯和发声方式。重建结果来自固定目标音色和模型学得的表达策略。

不保留：输入人的身份特征、口音指纹、未经授权的独特声线；这既是产品边界也是隐私指标。

## MVP 指标

| 维度 | 指标 | 首版目标 |
|---|---|---|
| 内容 | ASR WER/CER 相对原音频劣化 | 不超过 20% 相对值 |
| 音色 | 输出到目标声线的 speaker cosine | 显著高于输出到输入声线 |
| 实时性 | GPU RTF | `< 0.5` |
| 延迟 | 首包算法延迟 | `< 300 ms`，目标 `< 200 ms` |
| 连续性 | 边界爆音/掉帧 | 10 分钟测试无可闻硬断点 |
| 主观质量 | MOS | MVP 目标 `>= 3.2/5` |

数值是研发门槛而非最终承诺；应在固定硬件、数据切分和置信区间下报告。

## 阶段退出检查

- 建立 20–30 条覆盖短句、长句、静音、噪声、未见说话人的 golden set。
- 明确目标音色来源、授权范围和模型发布限制。
- 固定延迟的测量口径：采集、缓冲、模型、声码器和播放分别计时。
- 定义离线与在线一致性测试：相同音频整段和分块输入的输出差异可控。
