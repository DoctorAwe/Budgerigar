# 阶段 5：训练课程与损失函数

## 训练课程

### 5A：声学组件预训练

- 冻结内容编码器主体，训练 bottleneck、目标解码器和声码器。
- 使用目标说话人自重建，先得到稳定可发声系统。
- 单独检查声码器，避免把声码器伪影误判为转换问题。

### 5B：平行 any-to-one 转换

- 输入其他说话人的平行句，监督目标真人录音。
- 先用 neutral 数据，再加入情绪和噪声增强。
- 逐步解冻内容编码器顶部层，使用较小学习率。

### 5C：解耦和非平行扩展

- 加入输入说话人对抗头、内容一致性和伪配对。
- 对目标身份损失使用目标 speaker encoder；该 encoder 冻结。
- 监控身份损失是否通过损害可懂度“投机”。

### 5D：层级状态与流式微调

- 加入层级记忆，先从离线模型蒸馏。
- 随机切块、状态传递、truncated BPTT。
- 逐步减少 look-ahead，最终训练目标配置。

## 损失函数

```text
L = λmel Lmel
  + λstft Lmulti_res_stft
  + λcontent Lcontent
  + λtarget_spk Ltarget_speaker
  + λadv Linput_speaker_adversarial
  + λf0 Lnormalized_f0
  + λdur Lduration
  + λstate Lstate_consistency
  + λgan Lvocoder_optional
```

- `Lmel`：L1/L2 Mel 重建。
- `Lcontent`：冻结 ASR/SSL 表征上的内容一致性。
- `Ltarget_speaker`：输出靠近固定目标声线。
- `Linput_speaker_adversarial`：减少输入身份泄漏。
- `Lf0`：只比较归一化轮廓或目标风格 F0，不复制绝对输入 F0。
- `Lstate`：整段与分块状态/输出一致性。

权重不可只凭总损失选择；每次训练同时观察 WER/CER、目标/输入 speaker similarity、F0 统计和音频样例。

## 可复现性

- 配置保存数据版本、git commit、随机种子、依赖和硬件。
- checkpoint 包含模型、优化器、scheduler、AMP scaler 和采样器状态。
- 每 N steps 生成固定 golden set；禁止只挑最好听的样本。
- 从中断点恢复后验证下一批次与学习率一致。

## 退出条件

- 至少三次不同随机种子结果趋势一致。
- 训练无 NaN、状态爆炸和明显码本/韵律坍缩。
- 最佳 checkpoint 按预先定义的复合指标选择，而非人工试听挑选。
- 从零和从 checkpoint 恢复均有操作记录。
