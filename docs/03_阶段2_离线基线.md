# 阶段 2：离线基线模型

## 目标

先回答最小问题：模型能否从未见输入音色中提取完整句子，在输入期间保持静默，并在认为表达完整后以固定目标音色和自身语气复读？本阶段在连续时间轴上训练，但暂不追求最终低延迟声码器。

## 连续复读时间轴

训练 episode 同时包含输入流和输出流：输入句子出现时，输出监督为目标音色的自然静默；输入内容结束后先保留约 160–280 ms 的自然思考区间，输入侧继续提供环境静音或后续声音，之后输出侧才出现目标真人对同一句子的录音。模型不接收 `START/STOP` 标签，也不接收思考倒计时。

声学损失只说明“此刻应输出何种声音”；独立的连续输出意愿值可用目标语音能量作软监督，但它不是离散 action，也不由程序切换网络模块。推理时同一网络持续运行。

## 模块

### 内容编码器

使用预训练自监督语音编码器输出帧级特征，通过 bottleneck 降维。训练一个说话人分类器并使用 gradient reversal：主模型降低重建损失，对抗头尝试识别输入人，编码器则学习去除身份。

### 韵律编码器

输入归一化后的 log-F0、voicing、能量和时长。F0 按输入说话人或在线统计量标准化，只传递轮廓，不传递绝对音高。第一版可提供三档：

- `content_only`：完全由目标先验生成韵律；
- `rhythm`：保留时长、停顿和重音；
- `contour`：额外保留归一化句型轮廓。

### 目标身份

目标 speaker embedding 是固定参数或从授权 enrollment 音频提取后冻结。推理 API 不接受任意目标音色，从产品结构上保持 any-to-one。

### 声学解码器与声码器

解码器对每个连续 tick 输出目标 log-Mel 和一个连续的发声强度/置信度。首版采用已有预训练声码器或单独训练的目标域声码器。声码器不得成为内容编码器的梯度捷径。

## 平行训练

对相同 `parallel_id` 的源/目标音频做软对齐：

1. 把源音频放在 episode 的输入时间轴前段；
2. 把目标真人复读放在输出时间轴后段，前段输出是静默；
3. 通过连续隐状态保存句子内容，输出时间轴不与源帧强制一一对齐；
4. 随机化自然停顿和下一句到达时间，避免模型只按固定帧数计时；
5. 禁止把目标波形、人工句末 action 或真实目标长度作为推理输入。

非平行样本可用自重建、内容一致性和伪配对训练，但验证集只报告真实录音配对结果。

## 最小对照组

- B0：ASR 文本 + 目标 TTS，作为高延迟但内容稳定的上界参考。
- B1：无身份对抗的语音转换。
- B2：加入身份对抗与固定目标 embedding。
- B3：B2 + 受限韵律分支。

## 退出条件

- 未见输入说话人的输出可懂，且主观上接近目标声线。
- B2/B3 的输入说话人可识别率显著低于 B1。
- B3 相比 B2 改善节奏自然度，且不明显增加身份泄漏。
- 对 30 秒以上长音频整段推理无崩溃；此时不要求真正流式。
