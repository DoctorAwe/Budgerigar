# 阶段 2：离线基线模型

## 目标

先回答最小问题：模型能否从未见输入音色中提取内容，并以固定目标音色重建？本阶段允许整句输入，不引入层级记忆和严格实时限制。

## 模块

### 内容编码器

使用预训练自监督语音编码器输出帧级特征，通过 bottleneck 降维。训练一个说话人分类器并使用 gradient reversal：主模型降低重建损失，对抗头尝试识别输入人，编码器则学习去除身份。

### 韵律编码器

输入归一化后的 log-F0、voicing、能量和时长。F0 按输入说话人或在线统计量标准化，只传递轮廓，不传递绝对音高。第一版可提供三档：

- `content_only`：完全由目标先验生成韵律；
- `rhythm`：保留时长、停顿和重音；
- `contour`：额外保留归一化句型轮廓。

### 目标身份

目标 speaker embedding 是固定参数或从授权 enrollment 音频提取后冻结。推理 API 不接受任意目标音色，从产品结构上保持 any-to-one。

### 声学解码器与声码器

非流式解码器输出目标 log-Mel；首版采用已有预训练声码器或单独训练的目标域声码器。声码器不得成为内容编码器的梯度捷径。

## 平行训练

对相同 `parallel_id` 的源/目标音频做软对齐：

1. 内容编码源音频；
2. 目标音频提供 Mel 监督；
3. 用音素边界、DTW 或可学习时长预测解决说话速度差；
4. 禁止直接以目标波形作为编码器输入。

非平行样本可用自重建、内容一致性和伪配对训练，但验证集只报告真实录音配对结果。

## 最小对照组

- B0：ASR 文本 + 目标 TTS，作为高延迟但内容稳定的上界参考。
- B1：无身份对抗的语音转换。
- B2：加入身份对抗与固定目标 embedding。
- B3：B2 + 受限韵律分支。

## 退出条件

- 未见输入说话人的输出可懂，且主观上接近目标声线。
- B2/B3 的输入说话人可识别率显著低于 B1。
- B3 相比 B2 改善节奏自然度，且不明显增加身份泄漏。
- 对 30 秒以上长音频整段推理无崩溃；此时不要求真正流式。
