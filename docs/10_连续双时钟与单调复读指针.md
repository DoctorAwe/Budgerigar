# 连续双时钟与单调复读指针

## 为什么需要重构

双路径首轮在 200 steps 后得到 `behavior_pass=true`、`ablation_pass=true`，但 `content_pass=false`。完整复读 L1 为 `0.67967`；移除局部路径会恶化 `0.12436`，说明局部记忆确实被读取，却没有形成正确句子优势。

当前问题不是单纯的参数量不足：

1. 软 FIFO 用连续插值移动全部槽，相邻语音块会被反复混合，顺序边界逐渐模糊。
2. 解码器对局部槽做无约束全局注意力，没有“已读到哪里”的连续变量。
3. 输入句长与目标复读句长不同，逐帧 L1 无法自动提供可靠的源—目标单调对齐。
4. 抽象 token optimizer 适合提炼长期信息，不适合独自承担逐音素时间轴。
5. `behavior_pass` 只证明发声时机正确；CTC、检索和路径消融也不能替代最终复读内容验证。

因此停止仅增加位置 embedding、槽数或训练步数的小修，进入流式时序重构。

## 新结构

### 1. 因果声学事件编码器

输入音频按固定 tick 进入因果卷积/状态空间编码器。网络输出：

- 内容向量 `z_t`；
- 软事件写入强度 `w_t ∈ [0,1]`；
- 相对持续时间与韵律向量 `d_t`。

`w_t` 由网络根据声学变化、能量、VAD 证据和历史状态学习，不使用音素边界或“句子结束”程序事件。相邻帧只有在形成新的语音事件时才明显推进内容序列，减少固定 FIFO 的重复与混合。

### 2. 有序事件带

局部内容不再表示为无序槽集合，而是由 `(z_i, d_i, τ_i)` 构成的有序事件带。`τ_i` 是连续相对时间坐标，不是绝对位置标签。事件带保存复读所需的音素顺序和局部韵律。

写入采用可微的软追加/软合并：低写入强度更新当前事件，高写入强度逐渐形成下一事件。训练和推理使用同一运算，不存在硬切句。

### 3. AutoMachine 多层整体理解记忆

有序事件带只保存可重放的局部时间细节。AutoMachine token 层不再被解释成“一个槽对应一个时间片或一个单词”，也不进行简单的逐槽后移。

第 `l` 层 token 是持续优化的理解状态：

`H_l(t) = Optimizer_l(H_l(t-1), U_l(t), C_l(t))`

其中：

- `H_l(t-1)` 是该层此前形成的整体理解，而不是上一时间片的原样缓存；
- `U_l(t)` 是由下一层 token/声学事件提炼出的新证据；
- `C_l(t)` 是来自更高层的上下文反馈，使低层解释可以被整句语境修正；
- `Optimizer_l` 自己判断吸收、重组或保留多少信息。

各层职责如下：

- 底层理解 token：综合一段连续声学事件，形成稳定的音节、音素关系和局部韵律理解；它可以跨越多个事件，而非绑定单帧。
- 中层理解 token：反复读取底层已经优化过的状态，形成词组、语序、重音关系和短语边界的整体理解。
- 高层理解 token：在整句输入逐渐积累时持续修订，最终保存句子主干内容、语义关系、疑问/陈述倾向、情绪与复读意图。
- 最慢层上下文 token：跨越当前句子保留人格、对话上下文和稳定表达习惯，但不得覆盖当前句子的精确内容路径。

后层 token 因为持续接收“已经被前层理解过的信息”，并在自己的旧理解上反复优化，所以能够形成比单个时间片完整得多的句子表征。其有效记忆长度由优化器的保留/重组能力和更新门决定，不是 `tick × token 层数`。

层间信息流同时包含：

1. 自下而上的证据提炼：新声学事件逐层变成更完整的理解。
2. 自上而下的语境校正：高层整句假设帮助低层消除局部歧义。
3. 同层递归优化：每层在旧理解基础上吸收新证据，不因新 tick 到来而机械覆盖。

实现上采用递归层间注意力。第 `l` 层以自己的上一 tick 状态 `H_l(t-1)` 作为 query，注意上一 tick 的全部理解层以及当前 tick 已完成更新的较浅层；得到的 context 与新证据一起送入该层 optimizer，而 `H_l(t-1)` 继续作为递归 hidden state。由此，越深层越能主动选择此前各层中与当前整句假设相关的信息，而不是被动接收一个固定时间片。

为防止高层退化为句长或音色指纹，训练中对不同层设置不同探针：底层检查局部音素顺序，中层检查词序和短语内容，高层检查整句检索、文本恢复与语气类别。探针只用于训练和诊断，推理时不需要 transcript。

### 4. 连续双时钟

模型内部维护两个连续量：

- 写时钟 `write_phase`：描述输入内容积累进度；
- 读时钟 `read_phase`：描述复读已经消费到事件带的哪个位置。

二者是神经状态中的连续标量/向量，不是 LISTEN、END、READ 枚举状态。输入仍活跃时，模型通常提高写入而抑制读时钟；输入证据衰减后，网络根据完整性和上下文形成连续 `readiness`。

### 5. 学习型思考延迟

`readiness` 不直接触发朗读。它进入可学习延迟积分器，结合句长、内容复杂度、人格状态和历史节奏产生约 160–280 ms 的自然思考间隔。训练只监督早期不得发声、目标发声时机和输出质量，不提供“现在进入思考状态”的标签。

### 6. 单调复读指针

解码器不再对整个局部记忆任意跳转。每个输出 tick 预测非负推进量：

`read_phase(t+1) = read_phase(t) + softplus(Δ_t)`

随后用以 `read_phase` 为中心的可微局部窗口读取相邻事件，并同时读取多层整体理解 token。局部事件决定“下一段具体怎么发音”，高层理解决定“当前发音在整句话中是什么意思、后面应接什么、采用何种语气”。这样网络可以调整复读速度，但不能无代价地倒序、跳词或长期停在同一事件。

### 7. 人格化声学解码

声学解码器接收：当前局部事件、抽象上下文、读指针速度、韵律向量和固定可学习人格 embedding。输入说话人的音色只作为内容识别证据，不直接复制到输出；目标声线仍由目标真人语音监督。

## 训练阶段

1. 事件与单调对齐预训练：使用 transcript CTC/RNN-T 或软单调对齐，只验证事件顺序可恢复。
2. 目标声线复读训练：使用平行句对，采用软 DTW/单调注意力对齐后的 Mel 损失，避免把不同语速强行逐帧对应。
3. 连续时间轴训练：随机句长、尾部静音和 160–280 ms 延迟；监督提前发声率、启动误差和漏读。
4. 联合微调：降低辅助文字损失权重，以真实复读内容和音色为主。

真实数据、GPU 训练、软对齐缓存和音频验证均只在 Colab 执行。

## 必须通过的验证

- 时间轴：听句和思考区间误发声率 `<5%`，复读有声召回 `>90%`。
- 内容：正确目标必须显著优于打乱目标；检索至少达到随机机会的 3 倍。
- 单调性：读指针回退率为 0，重复停留和大跨度跳跃率受限。
- 完整性：短句、长句分别报告漏读、重复和截断指标，不能只给总均值。
- 消融：冻结读指针、移除事件带、逐层移除理解 token、切断自上而下反馈后，必须出现符合各自职责的退化。尤其要证明高层 token 保存的是整句理解，而不是句长/音色指纹。
- 稳健性：至少 3 个随机种子，报告逐句 bootstrap 95% 置信区间；小于置信区间的变化不得称为优化。
- 最终听测：输出必须在输入结束及思考间隔之后，以目标人格声线复读完整句子，而不是录音回放或平均声学模板。

## 参数策略

首版保持约 2–4M 参数。当前证据指向对齐机制而非容量不足；只有训练集和验证集同时受限、各路径消融明确有效且时序错误不再主导时，才扩大 hidden dimension 或层数。
