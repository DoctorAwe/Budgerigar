# 阶段 3：AutoMachine 式层级记忆

## 目标

用固定显存维护比局部注意力窗口更长的上下文，使长句中的语速、韵律状态和语义阶段保持连贯。详细抽象见 [../AutoMachine.md](../AutoMachine.md)。

## 状态层设计

建议先实现 8 个逐 tick 迁移的 token 层，再按 2 层一组观察其有效时间尺度。下表的周期是希望每组学到的特征跨度，不要求通过硬编码降频实现：

| 组 | 有效跨度示例 | 倾向保存 |
|---|---:|---|
| L0–L1 | 20–80 ms | 局部声学/音素过渡 |
| L2–L3 | 80–320 ms | 音节与局部重音 |
| L4–L5 | 320 ms–1.28 s | 词组、语速、短停顿 |
| L6–L7 | 1.28 s 以上 | 句子阶段、长期韵律趋势 |

跨度不是硬上限。每层更新器 `U_l` 通过遗忘门、写入门和候选状态决定保留旧摘要还是写入新信息，因此关键特征可以经过反复压缩后存活更久。若算力不足，再实验性地让深层降低更新频率。

```text
candidate_l = f_l(summary_from_lower, state_l)
write_l     = sigmoid(Ww[summary_from_lower, state_l])
forget_l    = sigmoid(Wf[summary_from_lower, state_l])
state_l'    = forget_l * state_l + write_l * candidate_l
```

Decoder 通过门控读取所有层。内容帧主要读取 L0/L1；韵律预测器可更多读取 L2/L3。

## 状态生命周期

- `start_session()`：全部状态初始化为可学习初值。
- 正常语音：按各层周期更新。
- 短静音：冻结 L2/L3，L0/L1 衰减。
- 长静音：所有层向初始状态软衰减，不立即硬清空。
- `reset()`：用户切换会话或输入源时硬清空。
- 输入丢包：注入 missing mask，禁止将零值误当真实静音。

## 防止“无限记忆”误解

状态维度固定，因此只能保存任务相关摘要，不能无损保留任意久的音频。训练目标应奖励长期有用信息，惩罚输入身份、噪声和瞬时细节进入高层。

建议加入：

- 跨分块状态一致性损失；
- 高层状态变化率正则；
- 从高层预测语速/句型阶段的辅助任务；
- 从高层预测输入说话人的对抗任务；
- 随机状态截断和 reset，防止依赖数据顺序。

## 实验

1. 10、30、120 秒同说话人长音频测试。
2. 与等参数量 1–5 秒滑动窗口模型比较。
3. 单独清空各层，观察内容、音色和韵律变化。
4. 探针分类器测试各层可恢复的音素、语速、句型和输入身份。
5. 人为改变前半句语速，检查后半句是否产生合理而非永久污染的影响。

## 退出条件

- 长句韵律一致性优于短窗口对照，内容指标不退化。
- 状态内存不随会话长度增长。
- 高层状态中的输入身份准确率接近随机或显著下降。
- 静音、丢包和 reset 行为均有自动化测试。
