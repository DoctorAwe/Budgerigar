# 单发音短时记忆路线

## 方向调整

长句复读同时包含语音识别、长时记忆、顺序对齐、启动判断和声学生成，失败后难以归因。新路线从单个短发音开始，先证明流式网络能听取、短时保存并在延迟后给出正确内容，再逐级恢复声音。

最终需求不变：输入和输出均为连续流；必须听完当前表达后再回应；中间存在短暂、可学习的思考间隔；模型内部不设置监听、结束、朗读状态机，不使用原音频回放或硬指针。

## 数据集

第一数据集采用 Free Spoken Digit Dataset（FSDD）：英文数字 0–9 的独立短录音。数据量小、标签无歧义，适合验证最小记忆闭环。原始采样率 8 kHz，训练时统一重采样到 16 kHz。下载、音频审计和真实训练只在 Colab 进行。

数据划分遵循官方测试规则：录音编号 0–4 为 test；5–9 固定为 validation；10–49 为 train。所有说话人均进入各 split，使第一轮专注于“是否记住发音类别”。通过后增加按说话人留出评估，防止模型只记说话人特征。

第二数据集采用 Google Speech Commands 的数字子集，扩大说话人、背景噪声和录音条件；它不作为第一轮阻塞项。

## S0：流式短发音到延迟 token

模型高层每 10 ms（16 kHz 下 160 个采样点）更新一次。推理接口接受任意长度的外部音频块，缓冲器只负责拼成完整的高层 tick；连续听觉前端保留采样级滤波状态，递归 GRU 持续更新短时理解。输入发音结束后继续输入环境静音；网络在完整度隐变量中自然累积信心，并在约 120–280 ms 后输出一个数字 token。

声学前端参考外周听觉而不是把 10 ms 当成独立声音：32 个可学习因果带通通道按对数频率初始化，滤波历史跨 chunk 延续；通道响应经过整流、压缩、2.5 ms 子帧包络和相邻活动变化率编码。这里是受耳蜗启发的工程近似，不宣称复现真实耳蜗或神经脉冲。10 ms 只是高层记忆更新频率，底层滤波在采样时间轴上连续；后续以转换质量优先，可根据消融在 5–20 ms 范围调整高层频率。

短时记忆主干使用 16 层递归 token 状态而非 GRU。每层 token 都保存独立的 96 维连续状态；一次更新中，token 通过因果层间注意力读取此前的同层/前层理解，并结合当前听觉证据用共享门控优化器修订。共享参数降低规模，各层 embedding 保留不同抽象职责。token 不对应固定时间片、字母或单词，后层可跨多个 tick 逐步吸收前层已经整理的信息。

训练时间轴的目标为 `blank` 或数字 0–9，但 `blank` 只是输出词表中的“此刻没有内容”，不是模型内部状态。推理时每个 tick 都执行同一个网络前向，不切换程序阶段，也不向模型提供句末、倒计时或目标输出位置。

验收指标：

- 无 teacher forcing 的数字准确率大于 95%；
- 输入发音尚未结束时的 token 误发射率低于 1%；
- 正确 token 首次发射位于输入结束后 120–320 ms；
- 输入消融后准确率接近随机水平 10%；
- 改变音频 chunk 边界后准确率下降不超过 2 个百分点；
- 保存逐 tick logits、完整度轨迹和混淆矩阵。

## S1：token 到短音频原音调复读

保留已经通过 S0 的流式听取与短时理解主干，新增连续声学记忆和神经波形解码器。数字 token 只作为训练辅助与诊断，不作为“识别文字后查表播放”的中间程序。输出必须由当前输入的连续表征生成，以保留当前说话人的音色、基频和时长。

验收除 token 准确率外还包括 SI-SDR、STOI、多分辨率 STFT、输入/重建说话人相似度和人工试听。随机打乱输入与目标后必须显著恶化，证明不是十个固定音频模板。

## S2：未知说话人与连续流

采用按说话人留出和 Speech Commands 数字子集，加入背景噪声、长短静音、不规则 chunk、连续多个数字以及发音中间停顿。循环状态跨 chunk 保持，但句间清理也由网络输出的连续置信度学习，不使用外部阶段机。

## S3：从单发音扩展到短词和音节组合

先扩展到 Speech Commands 单词，再训练两个数字/音节的组合。输出侧先验证 token 序列顺序，随后验证原音调音频序列。只有短序列不遗漏、不重复、不倒序，才恢复完整句子研究。
