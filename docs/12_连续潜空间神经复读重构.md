# 连续潜空间神经复读重构

## 1. 重构结论

停止继续改造 codec-token 分类模型。新的主线不预测离散 EnCodec token，也不使用 token bank、token tape、显式读写指针、固定播放速率或 `LISTEN/THINK/PLAY` 状态机。

任务重新定义为：模型持续接收真实音频流，将已经听到的声音编码为可学习的连续神经表征；当网络自身认为表达已经完整，并经过由隐状态形成的短暂内化过程后，用神经声学生成器重新合成所听内容。第一阶段重建输入本人的声音；通过后才在生成端改变音色和语调。

## 2. 必要的信息容量

完整复现任意长度音频不可能只依靠一个固定维度向量。固定状态可以保存句意，却无法无损保留任意长语音中的音素顺序、时长、基频和细节。因此模型仍需要随输入长度增长的信息容量，但它必须是网络学到的连续激活，而不是可直接回放的原始音频、codec token 或整数地址表。

新结构同时维护两类互补表征：

- 连续声学记忆：因果编码器每隔约 13–20 ms 产生一个连续向量。向量由卷积和状态空间网络学习，可被后续层重写和上下文化，不能直接当作输出。
- 整体理解状态：多尺度循环/状态空间层持续整合已有声学表征，形成音素关系、韵律轮廓、句子完整度和表达意图。它不承担逐采样点存储。

这两者都是普通神经网络激活，并共同参与梯度训练。不存在“保存原 token 后原样读取”的旁路。

## 3. 模型结构

```text
24 kHz 流式波形
  ↓
因果连续声学编码器（strided Conv + residual SSM）
  ↓
上下文化连续潜序列 ───────────────┐
  ↓                              │ learned cross-attention
多尺度整体理解状态                │
  ↓                              ↓
连续复读意愿 / 发声强度 ─→ 自回归潜声学生成器
                                 ↓
                         因果神经波形解码器
                                 ↓
                           24 kHz 输出流
```

### 3.1 连续声学编码器

- 输入为波形块，不再预先提取 EnCodec token。
- 使用因果卷积逐级降采样到约 50–75 Hz，每个位置输出连续向量。
- 在降采样层之间加入残差状态空间块，使当前表征包含先前上下文。
- 训练时随机改变输入 chunk 大小，避免模型依赖固定分块边界。

### 3.2 整体理解网络

- 使用不同时间尺度的递归状态空间层持续修订理解，而不是让一层对应一个时间片或单词。
- 较慢层吸收较快层已经上下文化的证据，并保留自己的上一时刻状态。
- 高层状态为句子完整度、注意力查询、预期输出长度和全局韵律提供条件。
- 不输入句末标签、阶段标签或倒计时；网络只看到音频、环境静音和自身历史状态。

### 3.3 自然启动机制

模型每个 tick 输出连续的发声强度与复读意愿。训练时间轴仍包含“完整输入—约 160–280 ms 静默—复读目标”，但模型内部不出现离散阶段，也不由 runtime 计时触发。长句内停顿、未完成短语和不同长度的尾部静音必须加入训练，以迫使网络根据内容完整度而不是固定静音长度作判断。

### 3.4 神经生成器

- 解码器用自身上一时刻的连续潜声学输出作为反馈。
- 解码器对连续声学记忆做多头软注意力，同时由整体理解状态调制。
- 注意力位置不受整数地址或固定单调公式控制；顺序通过训练目标、相对位置表征和覆盖正则学习。
- 解码器先生成连续声学潜变量，再由因果神经波形解码器产生音频块。
- 所有输出样本均为网络计算结果，不允许返回输入数组、输入 token 或缓存音频。

## 4. 损失函数

第一阶段不再采用 8×1024 token 分类交叉熵，改为：

1. 多分辨率 STFT 损失：约束频谱结构和清晰度。
2. 波形/尺度不变信号损失：约束整体重建与相位一致性。
3. Mel 感知损失：只作为辅助，不再单独决定成败。
4. 发声强度损失：约束听取和思考期间静默、复读期间发声。
5. 时长损失：预测输出剩余量和总时长，但不把预测值变成程序化计时器。
6. 内容一致性损失：用冻结的预训练语音表征比较输入与输出，防止平均声学模板。
7. 注意力覆盖与多样性正则：减少只关注少数片段、重复和漏读；不监督固定读取地址。

波形判别器只在稳定重建后引入。过早加入 GAN 容易让输出听起来像语音，却不包含正确句子。

## 5. 分阶段实施

### 阶段 R0：连续自编码器可行性

只训练 `waveform → continuous latent → waveform`，暂不加入延迟复读。使用同一批 CMU ARCTIC 原音频，验证连续瓶颈可以清晰重建不同句子。此阶段失败时禁止接入整体复读模型。

通过条件：验证集输出可播放；SI-SDR、STOI 和多分辨率 STFT 明显优于静音及平均模板；冻结语音表征的正确输入相似度显著高于打乱输入。

### 阶段 R1：完整听取后的神经复读

接入连续 episode、整体理解网络、软注意力生成器和发声强度头。先采用较高比例的连续潜变量 teacher forcing，再逐步降低；验证必须完全关闭 teacher forcing。

通过条件：听取和思考误发声率分别低于 1%；输出启动位于输入结束后 160–320 ms；正确输入的内容相似度和 ASR 指标显著优于打乱输入；不得只凭训练损失宣布通过。

### 阶段 R2：闭环生成稳定性

训练时增加模型自身输出反馈、随机句长、长句内停顿、噪声和不规则输入 chunk。检查长句中的遗漏、重复、倒序和累计漂移。

通过条件：至少三个随机种子稳定；输出时长误差低于 5%；内容错误不随句长快速恶化；真实 Colab T4 推理达到可接受实时系数。

### 阶段 R3：音色解耦

将连续潜空间拆成内容、韵律和说话人条件。内容路径接受说话人对抗约束，生成器加入获得授权的目标说话人 embedding。先只改变音色，内容指标不得明显低于 R2。

### 阶段 R4：语调与人格

加入稳定人格向量和全句韵律规划器。人格改变基频范围、能量、停顿习惯和表达强度，但不能覆盖内容一致性约束。思考间隔的分布也可成为人格的一部分。

### 阶段 R5：Colab 流式演示

使用随机音频 chunk 进行真实流式验证，记录 T4 型号、峰值显存、实时系数和端到端延迟。最终用 Gradio 接收麦克风流；工程层只负责缓冲和安全超时，不替模型决定句子结束或复读启动。

## 6. 当前实验的处置

- `codec_token_tape_copy` 与 `fully_learned_neural_repeater` 均保留为失败对照，不再扩训。
- 已生成的 EnCodec payload 不删除，可用于客观对照和日后声学分析，但不再是新模型输入。
- CMU ARCTIC manifest、原始波形、split 和环境报告继续复用，不重新下载数据集。
- 下一项代码工作是独立实现 R0 连续波形自编码器及 Colab smoke notebook，避免继续修改旧 token 模型。
